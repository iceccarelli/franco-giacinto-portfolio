# Franco Giacinto Oller Grimaldi — Master Hardwood Flooring Portfolio

A premium Next.js 14+ portfolio website for Franco Giacinto, master hardwood flooring craftsman serving the Greater Toronto Area. Built with TypeScript strict mode, pure CSS custom properties, glass-panel design, and 7 original wood-themed canvas visualizers.

## Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript (strict mode)
- **Styling:** Pure CSS with custom properties (no Tailwind)
- **Font:** Inter (Google Fonts)
- **Palette:** Walnut/charcoal background + amber/gold accents

## Features

- 7 original rotating canvas visualizers (Wood Grain Flow, Sanding Map, Install Pulse, Stain Diffuser, Alignment Grid, Curing Monitor, Inlay Designer)
- Portfolio gallery with category and type filters
- Interactive floor cost calculator
- Live RSS feed from flooring industry sources
- Contact form with service selection
- Glass-panel frosted design system
- Mobile-first responsive layout
- LocalBusiness JSON-LD structured data
- Sticky header with scroll-hide behavior

## Deploy to Vercel

```bash
git init
git add .
git commit -m "Initial commit: Franco Giacinto Portfolio"
git branch -M main
git remote add origin https://github.com/iceccarelli/franco-giacinto-portfolio.git
git push -u origin main
```

Then import at [vercel.com/new](https://vercel.com/new) and click Deploy.

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
