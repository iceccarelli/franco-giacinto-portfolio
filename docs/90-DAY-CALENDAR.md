# 90-day calendar

## Days 1–7 — facts and host

- Confirm every field in `data/company.ts` is true, or delete it.
- Attach `greenhardwood.ca` on Vercel. Set `NEXT_PUBLIC_SITE_URL`.
- Open Google Search Console + Bing Webmaster on that host.
- Submit `/sitemap.xml`.
- Run `npm run indexnow` once the host is canonical.
- Create or claim Google Business Profile as **Green Hardwood** with the same NAP.

## Days 8–21 — Pack 01 + 02

- Merge Pack 01 (`content/authority-pack-01`).
- Merge Pack 02 (`feat/answers-glossary-methods`).
- `npm run verify` green.
- Footer links to /methods and /answers.
- Photograph five real stair jobs and five real installs. Replace method illustrations on service pages only when the photo is yours.

## Days 22–45 — proof

- 15 Google reviews that mention stairs or installation by name.
- Upload job photos to GBP weekly.
- One guide promotion: retread cost + carpet-to-oak.
- Trade email to 20 realtors / builders pointing at `/trade` and `/stairs`.

## Days 46–90 — tighten, do not sprawl

- Watch GSC queries. Add a paragraph to an existing page before you add a new URL.
- Refresh price bands if the market moved.
- Record a 45-second stair retread video for `/stairs` and GBP.
- Only then consider `stairs.greenhardwood.ca` as a subdomain of the same project.
